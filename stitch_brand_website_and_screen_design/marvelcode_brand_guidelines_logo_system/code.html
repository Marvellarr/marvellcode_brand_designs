05 // COMPLIANCE

5 Golden Brand Commandments

Mandatory Protocol
01
Use Logo Consistently

Always employ the verified vector marks. Never alter the 3D angle, recolor facets arbitrarily, or replace the slash glyph.

02
Keep Clear Space

Preserve a perimeter minimum equal to 1X height of the code element around the lockup boundary.

03
Exact Hex Fidelity

Stick precisely to verified tokens (#2563EB, #8B5CF6, #0B1020). Never compromise with desaturated tones.

04
Strict Typography

Montserrat for headings, Inter for high-density reading, JetBrains Mono for telemetry metrics and code blocks.

05
Global Cohesion

Ensure cross-platform alignment across IDE extensions, web portals, mobile touchpoints, and hardware gear.
